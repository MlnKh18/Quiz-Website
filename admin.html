Pengaturan Sistem

Konfigurasi koneksi Google Sheets dan keamanan panel admin

Koneksi Google Sheets

Hubungkan kuis dengan Google Spreadsheet melalui Google Apps Script Web App URL. Nilai siswa akan otomatis masuk ke file Excel/Sheets Anda.

1

Buka Google Spreadsheet yang ingin dijadikan database nilai (ID Spreadsheet: 1YuGcdRin7BLdRXitxivZa3NJ3-Kno4C_-nlqAR06rbA).

2

Buka menu Extensions → Apps Script, salin kode di bawah ini lalu paste ke editor Apps Script:

Kode Google Apps Script (Code.gs) 
const SPREADSHEET_ID = '1YuGcdRin7BLdRXitxivZa3NJ3-Kno4C_-nlqAR06rbA';
const SHEET_NAME = 'Jawaban';

function doGet() {
  return ContentService
    .createTextOutput(JSON.stringify({ ok: true, message: 'Web App aktif' }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents || '{}');
    const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
    const sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME);

    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        'Timestamp', 'Nama Siswa', 'Kelas', 'Skor Benar',
        'Total Soal', 'Nilai', 'Jawaban JSON'
      ]);
    }

    sheet.appendRow([
      new Date(),
      data.nama || '',
      data.kelas || '',
      data.skor || 0,
      data.total || 15,
      data.nilai || 0,
      JSON.stringify(data.jawaban || {})
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: String(error) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
3

Klik Deploy → New Deployment, pilih tipe Web App, ubah Who has access menjadi Anyone, lalu klik Deploy.

4

Salin Web App URL yang dihasilkan dan tempelkan pada kolom di bawah ini, lalu klik Simpan URL Web App.
